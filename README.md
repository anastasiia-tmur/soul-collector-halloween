# Собиратель душ

Хэллоуинская игра-змейка в браузере. Скелет-пастух ходит по кладбищу, собирает сбежавшие души в хвост и ведёт их через ворота. У тебя 2 минуты до рассвета.

## Как играть

- Управление: стрелки или WASD на компьютере, свайп на телефоне. Чтобы начать, нажми пробел (на телефоне коснись экрана).
- Касайся блуждающих душ: они встают в хвост. Выстрой цепочку в том порядке, который показан над полем, и проведи её через ворота в правом верхнем углу.
- 🎃 Тыква забирает последнюю душу из цепочки.
- 🕯️ Касание свечи заканчивает игру.
- Если врезаться в свой хвост, цепочка рвётся и души разбегаются.
- Поле замкнуто в кольцо: уйдёшь за край и окажешься с другой стороны.
- Музыку можно выключить кнопкой рядом с таймером (или клавишей M).

## Как запустить

Игра состоит из одной страницы (`index.html`) и папки `assets`. Выложи страницу на любой хостинг статических файлов (например, GitHub Pages). Файл `index.html` нельзя просто открыть без папки `assets`: картинки и музыка лежат в ней. Заголовки используют шрифт Rubik Wet Paint с Google Fonts, поэтому для них нужен интернет.
